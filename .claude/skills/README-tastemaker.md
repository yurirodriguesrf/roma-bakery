## Skill disponível

| Skill | Para que serve |
| --- | --- |
| `tastemaker` | Gera UI genuinamente bonita e alinhada à marca em vez de "AI slop" genérico — usar ao construir, estilizar ou revisar UI/landing pages/dashboards, ao extrair o estilo de referências (screenshots/URLs), ou ao auditar por que uma UI parece genérica. Inclui a sub-skill `ideagram` para geração de ilustrações estilo undraw. |

Inclui scripts Python auxiliares (extração de paleta, contraste, favicons,
ícones, fotos) e um guard de rede (`_netguard.py`) que restringe os domínios
externos que esses scripts podem acessar.
