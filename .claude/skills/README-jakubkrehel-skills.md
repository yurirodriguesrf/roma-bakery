## Skills disponíveis

| Skill | Para que serve |
| --- | --- |
| `better-interface` | Combina todas as `better-*` numa única revisão (acessibilidade, layout, copy, tipografia, cor, polish). |
| `better-accessibility` | Ajuda o projeto a atender padrões e boas práticas de acessibilidade. |
| `better-colors` | Constrói sistema de cores: paletas, tokens semânticos, conversão de formatos, contraste. |
| `better-layout` | Agrupamento, alinhamento, ordem de leitura, disclosure progressivo. |
| `better-typography` | Escala tipográfica, espaçamento, variable fonts, OpenType, wrapping, truncamento. |
| `better-ui` | Polimento de UI: border-radius concêntrico, alinhamento óptico, profundidade, ícones contextuais, hit areas. |
| `better-writing` | Melhora o copy do produto. |
| `interface-review` | Revisão detalhada cruzando UI, tipografia, layout, cor, copy e acessibilidade. |
| `explain-interface` | Explica como algo foi construído na web. |
| `variant` | Constrói múltiplas variantes de um componente para iterar e escolher. |
| `break` | Renderiza um componente em todos os estados/cenários numa página temporária e faz stress test. |
