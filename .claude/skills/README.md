## Skills disponíveis

| Skill | Para que serve |
| --- | --- |
| `emil-design-eng` | Skill principal: filosofia de UI polish, design de componentes e decisões de animação. |
| `animate` | Constrói uma animação do zero escolhendo curva, duração e propriedades corretas. |
| `animate-expo` | O mesmo padrão para React Native / Expo: gestos, sheets, haptics, transições de tela. |
| `review-animations` | Revisa as animações existentes de forma rigorosa. |
| `improve-animations` | Audita todas as animações do codebase e gera planos priorizados. |
| `find-animation-opportunities` | Encontra lugares na UI que se beneficiariam de movimento — e o que não animar. |
| `animation-vocabulary` | Vocabulário correto para descrever a animação que você quer. |
| `apple-design` | Princípios de design e movimento da Apple, traduzidos para a web. |
| `write-swift` | Swift moderno: value types, concorrência Swift 6, generics, Swift Testing. |
| `pick-ui-library` | Escolhe a biblioteca certa para a tarefa em vez de improvisar componentes. |
| `prototype` | Gera várias versões de um trecho de UI com um switcher para comparar. |
| `ask-sonner` | Guia do Sonner (biblioteca de toasts): setup, estilos, receitas e problemas comuns. |
