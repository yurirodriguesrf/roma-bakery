## Skills disponíveis

| Skill | Para que serve |
| --- | --- |
| `web-video-presentation` | Transforma artigos/roteiros em apresentações web 16:9 clicáveis, gravável como vídeo, com narração opcional. |
| `web-design-engineer` | Constrói/redesenha artefatos visuais web (páginas, dashboards, protótipos, slides, dataviz) em HTML/CSS/JS/React. |
| `gpt-image-2` | Geração/edição de imagem com GPT Image 2 — 80+ templates estruturados (pôsteres, UI, produtos, infográficos, etc). |
| `beautiful-article` | Transforma material (URL/PDF/DOCX/Markdown/texto) em um artigo HTML único, offline, bonito e compartilhável. |
| `kb-retriever` | Assistente de busca e Q&A sobre um diretório de base de conhecimento local. |

## Atualizar

Repita a instalação manual a partir de https://github.com/ConardLi/garden-skills, ou use a CLI `skills` do projeto, se aplicável.
